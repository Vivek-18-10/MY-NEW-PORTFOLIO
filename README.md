
# MY NEW PORTFOLIO
## Web Development Lab 3 – Responsive Personal Portfolio Website

### Project Description
A modern, responsive personal portfolio website developed using HTML5 and CSS3. It showcases personal information, technical skills, projects, and contact details with an interactive and professional design.

### Objectives
- Build a one-page responsive portfolio website.
- Implement Flexbox for layout and alignment.
- Use CSS Grid to display skills and projects.
- Create responsive layouts using media queries.
- Apply relative CSS units for scalable design.
- Add hover effects, transitions, transforms, and keyframe animations.

### Technologies Used
- HTML5
- CSS3
- Google Fonts
- Visual Studio Code
- GitHub

### Website Sections
1. Header and Navigation
2. Hero Section
3. About Me
4. Skills
5. Projects
6. Contact Form
7. Footer

### CSS Features
- Flexbox layout
- CSS Grid layout
- Mobile-first responsive design
- Media queries
- Relative units (rem, em, %, vw, vh)
- Hover effects
- CSS transitions
- CSS transforms
- Keyframe animations
- Google Fonts typography
- Gradient backgrounds

### Responsive Breakpoints
- Mobile: Below 600px
- Tablet: 600px to 900px
- Desktop: Above 900px

### How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the website using Live Server.
5. Resize the browser to test mobile, tablet, and desktop layouts.
